# 🛒 Amazon Clone - Full-Stack React & Firebase Application

An enterprise-grade **Amazon E-Commerce Clone** built with **React.js**, **React Context API**, **Firebase Authentication**, **Firestore Database**, and **Stripe API Payment Processing**.

---

## 🚀 Features

- 📦 **Amazon Header & Navigation**: Includes location selector, search bar, user sign-in status, and real-time shopping cart badge.
- 🛍️ **Product Catalog Feed**: Dynamic product cards with pricing, star ratings, and instant *"Add to Basket"* triggers.
- 🛒 **Shopping Basket & Checkout**: Interactive item management, subtotal calculation, and item removal.
- 🔐 **Firebase Authentication**: Custom Amazon-style sign in & registration flow with persistent login sessions.
- 💳 **Stripe Payment Gateway**: Secure card payment checkout powered by Stripe API.
- 📜 **Order History Log**: Real-time receipt tracking saved to Firestore database.

---

## 🛠️ Tech Stack

- **Frontend**: React.js, React Router, Context API, CSS Grid & Flexbox
- **Backend Services**: Firebase Auth, Cloud Firestore, Firebase Cloud Functions
- **Payments**: Stripe API (`@stripe/stripe-js`)

---

## 💻 Local Development Setup

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm start
   ```
   Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

3. **Build for Production**:
   ```bash
   npm run build
   ```
